# Night Loom production record

The four JPEG plates were created for this proposal with built-in OpenAI ImageGen. Street and wardrobe began from text. Booth and hall used the street plate as their only reference. The [prompt record](prompts.txt) contains the exact requests. Each original 1536 × 1024 plate was exported to JPEG. The block plan was drawn directly in SVG and the local HTML reader was written for this proposal.

All files are contributed under the [repository MIT license](../../../LICENSE) to the extent rights exist. Credit LootTown contributors, Night Loom v1.0 (AI-assisted). For future assets record the creator, source URL or source file, license, attribution, modifications, dimensions, and version. For GLBs include the pivot, triangle count, atlas size, rig and clips.

The production targets in the brief await a real 3D build. The offline reader displays still images and provides text alternatives for each plate.
