# River Rooms asset manifest

The art and diagram are original contributions from oppo2357 for LootTown, offered under the [project MIT license](../../../LICENSE) to the extent the contributor holds rights. All characters, venues and communities pictured here are fictional. Git City's browser-first approach was a project reference. No Git City assets or code were used.

For production assets, record the asset ID, path and version, author, original source URL or source file, rights and attribution, any AI tool and reference inputs, edits, units and pivot, rig and clips, LOD triangle counts, texture size, and static fallback. The GLB filenames and rig instructions in the brief are proposed conventions. These plates contain no production meshes.
