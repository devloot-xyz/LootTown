# Architecture decision: browser foundation

Status: technical stack accepted for the scaffold, 2026-11-03. The visual design remains open.

Use TypeScript, React 18, React Three Fiber 8, Three.js, Vite 6, npm and Node 24. DevLoot's current client uses React 18 and Node 24. Registry peers checked on 2026-11-03: Fiber 8.18.0 accepts `react`/`react-dom >=18 <19`; Drei 9.122.0 accepts React 18 and Fiber 8. Fiber 9 targets React 19 and Fiber 10 is alpha. Exact versions and `package-lock.json` keep the scaffold reproducible. Embedding in the DevLoot host still requires a real bundling and dependency-deduplication test.

React will own UI and app state; Fiber allows a future Three scene to participate in React lifecycle. Plain Three.js would need manual UI/scene synchronization; Babylon.js would add another scene/component model to this React host. No comparative FPS benchmark was run. Vite supplies the standalone dev and build shell. The current app intentionally has **no Canvas or placeholder world**; installed 3D packages are readiness for future issue work, not a claim of visual progress. No new backend, Next.js app, editor service, or monorepo is included.

`src/domain` holds approved avatar bands and identity deduplication. `src/contracts` validates the proposed venue projection. `src/seed` generates a versioned synthetic envelope whose individual venues use that projection; `public/fixtures/large.json` is served without being rendered by the bootstrap. A future public adapter needs an actual DevLoot endpoint, pagination/snapshot consistency, and truthful freshness/coverage. Standalone cross-origin reads require DevLoot to permit that origin; an embedded same-origin integration can use host context. Never expose GitHub tokens or wallet secrets in browser configuration. Proposed host callbacks include `selectCommunity`, `selectPerson`, and `openBounty`; DevLoot owns navigation, authorization and payments. No `/loottown` endpoint exists in the inspected DevLoot API.

glTF/GLB is the intended art pipeline; Blender is optional. Visual work must start from an approved art direction and record asset author, source, license, attribution, modifications, geometry/texture budget, rig, and animation clips. GitCity (srizzon/git-city) is AGPL-3.0 and is an idea reference only; no source or assets are copied.

Future world and venue work must provide a DOM equivalent, keyboard navigation, a WebGL-unavailable path, `prefers-reduced-motion`, a motion control, and opt-in audio. The 40-community fixture is **not** a crowd performance test. `InstancedMesh` reduces draw calls for repeated meshes; it does not guarantee thousands of independently animated skinned characters. Establish target devices, measure draw calls/frame time/memory/load, then define visibility limits, LOD, and animation budgets. Do not assert FPS without a measured target.
